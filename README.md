# springboot-multidb-project
Spring Boot Multi-Database project demonstrating integration with MySQL and PostgreSQL in a single application using Spring Data JPA and Hibernate.

A Spring Boot project demonstrating how to connect and work with multiple databases in a single application.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- PostgreSQL
- Maven

## Project Description

This project demonstrates integration of MySQL and PostgreSQL databases with a single Spring Boot application.

## Features

- MySQL database integration
- PostgreSQL database integration
- Multiple DataSources
- Spring Data JPA
- REST APIs
- Hibernate ORM
